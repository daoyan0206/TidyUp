# TidyUp · 疯狂收杂物

本仓库用于发布 Godot 4.5.1 导出的正常 H5 试玩版，游戏内标题为“逼疯强迫症”。不包含 Godot 源项目、关卡调试器、玩家存档或服务器密钥。

## 在线试玩

GitHub Pages 启用后：[点击在线试玩](<https://daoyan0206.github.io/TidyUp/>)。

需使用支持 WebAssembly 与 WebGL 2 的现代浏览器；运行时较大，加载可能需要等待。

## 操作

- 点击未被压住的物品，收进对应任务盒；暂无对应任务时进入收纳格。
- 小关卡一屏固定，大关卡单指拖动查看；双指或鼠标滚轮缩放。
- 任务、场景和收纳格全部清空，最后一件飞行结束后获胜。

这是 H5 试玩，不是微信或抖音小游戏正式发布。广告奖励是开发模拟流程，排行榜尚未接入正式服务。

## 发布说明

仅包含静态网页、JavaScript、WebAssembly、游戏数据包和图标。构建使用单线程 Web 模板，不依赖 GitHub Pages 无法提供的跨源隔离响应头。

网页从仓库分支根目录发布；`.nojekyll` 禁用 Jekyll，`.gitattributes` 保持导出文件原始字节。后续更新应替换对应正常 H5 文件并提交，勿上传私人存档或调试版本。
